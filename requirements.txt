# Docker is likewise a SYSTEM requirement, not a pip package, and the `docker`

# container stack through the `docker` CLI via subprocess (install.py
# get_docker_compose_cmd(), start_companion_stacks(), run_docker()), so the SDK
# would be a second, unused way to do the same thing. Install the Engine:
#     https://docs.docker.com/engine/install/
# `bash scripts/install_system_deps.sh` checks for it and prints that URL when
# it is missing. See also:  docker/README.md
##
# Browser automation likewise needs a real Chromium BINARY, which no pip package
# can supply. Two parts, both required:
#   1. the browser   -- fetched by Playwright into ~/.cache/ms-playwright
#   2. the flags     -- see the AppArmor note below
#   npx playwright install chromium      # binary only; do NOT use --with-deps
#                                     (that shells apt and needs root)
#   npx playwright install-deps chromium # system libs; run once WITH sudo
# Hermes also autoinstalls the binary on first local use
# (browser_tool_install._maybe_autoinstall_chromium), gated by
# security.allow_lazy_installs, and honours AGENT_BROWSER_EXECUTABLE_PATH.
#
# APPARMOR -- READ THIS BEFORE REPORTING A BROWSER BUG.
# Ubuntu ships kernel.apparmor_restrict_unprivileged_userns=1, which blocks the
# user namespaces Chrome's zygote sandbox needs. The symptom is NOT a missing
# browser: Chromium exits with a FATAL zygote_host error, or
# "Chrome exited early ... without writing DevToolsActivePort". No amount of
# reinstalling Chromium fixes it. The fix is to pass --no-sandbox:
#   export AGENT_BROWSER_ARGS="--no-sandbox,--disable-dev-shm-usage"
# (comma-separated in ONE value, not separate argv entries). Confirm with:
#   npx agent-browser --args "--no-sandbox" open http://example.com
# Prefer AGENT_BROWSER_ARGS over patching hermes-agent; the env var is the
# supported override and survives `hermes update`.
#
# Skill-scoped heavy deps (torch, transformers, marker, pymupdf, pptx, docx,
# openpyxl) are intentionally NOT here — each skill lists its own prerequisites.
#
# Google sync (gmail_sync.py / gcal_sync.py) uses its OWN isolated venv so
# `hermes update` can never break it silently:
#   bash scripts/setup_google_venv.sh
# ==============================================================================
