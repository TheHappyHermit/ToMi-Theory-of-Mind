# Beliefs

Part of the active wiki. The user's current interpretations, graded by epistemic certainty. A claim is not a belief because it is asserted; it is here because it is held at a stated confidence.

## Sub-folders

- [Claims](Claims/index.md) — Checkable assertions.
- [Hypotheses](Hypotheses/index.md) — Unconfirmed explanations or predictions.
- [Theses](Theses/index.md) — Broader interpretations built from multiple claims.
- [Principles](Principles/index.md) — Normative rules governing how the user decides.
