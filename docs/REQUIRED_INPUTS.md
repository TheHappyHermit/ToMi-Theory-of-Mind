# Required Inputs

This file is referenced by [INSTALL.md](INSTALL.md). Fill in these values during initial setup.

```markdown
# Required Inputs

Configure the following before deploying services:

- [ ] **LLM Provider API Key** — For Honcho's deriver (user-model derivation)
  - If Hermes is setting up the system automatically: Honcho will inherit the same provider and API key that Hermes is already configured to use (from your Hermes `.env` file at `${HOME}/.hermes/.env`). No extra input needed.
  - For manual setup, choose one:
    - Local OpenAI-compatible endpoint (llama.cpp, LM Studio, vLLM): set `LLM_OPENAI_BASE_URL`, `LLM_OPENAI_API_KEY`, and the model entries (`DERIVER_MODEL_CONFIG__*`, `SUMMARY_MODEL_CONFIG__*`, `DIALECTIC_LEVELS__*`) — see `docker/.env.example`
    - Embeddings: set `EMBEDDING_MODEL_CONFIG__MODEL` + `EMBEDDING_MODEL_CONFIG__OVERRIDES__BASE_URL` (Ollama works well, e.g. `qwen3-embedding:8b`)
  - If not configured: Honcho runs in read-only mode (no derivation)

- [ ] **SearXNG Secret** — Auto-generated by Hermes if not provided
  - Command: `openssl rand -hex 32`
  - Stored in `docker/.env` as `SEARXNG_SECRET`

- [ ] **Brain Search** — For semantic search and fact extraction
  - ZeroEntropy: `ZEROENTROPY_API_KEY` (default embedding + reranker)
  - OpenAI: `OPENAI_API_KEY` (fallback for vector search)
  - Anthropic: `ANTHROPIC_API_KEY` (optional, improves search quality)
  - Note: These are read from your Hermes `.env` file automatically during auto-setup. For manual setup, fill them in `docker/.env`.

- [ ] **Embedding Server** — REQUIRED for brain sync. Without it, sync writes nothing.
  - `brain_sync.py` needs an OpenAI-compatible `/v1/embeddings` endpoint. It does **not**
    use Ollama's native `/api/embed` path, and it does **not** load `.env` — it reads
    `os.environ` only, so the code's built-in default is what a cron job actually uses.
  - Working reference setup: `llama-server` in Docker on the main server.
    Note the image is on **GitHub Container Registry** (`ghcr.io`), not Docker Hub —
    `hub.docker.com/r/ggml-org/llama.cpp` does not exist.
    ```
    docker run --gpus all -p 18082:8082 \
      ghcr.io/ggml-org/llama.cpp:server-vulkan \
      -m /models/Qwen3-Embedding-4B-Q8_0.gguf --embedding --pooling last \
      -ngl 99 -c 8192 --host 0.0.0.0 --port 8082
    ```
  - Set in `docker/.env`:
    ```bash
    BRAIN_OLLAMA_URL=http://<host>:18082
    INFERENCE_EMBED_URL=http://<host>:18082
    BRAIN_EMBED_MODEL=/models/Qwen3-Embedding-4B-Q8_0.gguf
    BRAIN_API_MODE=openai
    ```
  - **Verify before trusting it.** A wrong endpoint does not fail loudly — the sync
    records a timestamp and reports `files=0`, which looks like success:
    ```bash
    curl -s http://<host>:18082/v1/models          # must list your embedding model
    python3 scripts/brain_sync.py --source active-wiki   # expect Scanned > 0
    ```
  - **Dimension note:** Qwen3-Embedding-4B returns **2560** dimensions. The
    `embeddings` column is **2000**. The server ignores a `dimensions` parameter, so
    `brain_sync.py` truncates client-side. This is already handled — just don't be
    surprised by the mismatch, and don't "fix" it by changing the column.

- [ ] **Brain Search Service** — for `verify_brain_sync.py` to pass
  - The verifier queries the Hermes dashboard, **not** an LLM API:
    `BRAIN_API_URL` (default `http://localhost:8088`) + path `/api/brain/search`
  - It is a **GET** taking `?q=`, returning `{"query":..., "results":[...]}`.
  - A 404 here means wrong service or wrong route, not an empty brain.

- [ ] **GitHub Token** — For automated config backups (optional)
  - If not provided, backup scripts skip git push

- [ ] **Researcher Profile Model** — Which model handles web research
  - Default: inherits global model from Hermes config
  - Can be a cheaper model (research is high-volume)
```

## How to Use

### Auto-Setup (Hermes does the work)

1. Tell Hermes: "Set up the Hermes Brain from the repository"
2. Hermes reads your existing `.env` file at `${HOME}/.hermes/.env` and auto-fills the provider/API key configuration
3. Hermes generates the SearXNG secret automatically
4. Hermes prompts you only for inputs it cannot infer (e.g., Brain Search keys if not present)

### Manual Setup

1. Open `docker/.env.example` and copy it to `docker/.env`
2. Fill in the required fields
3. Follow the steps in [INSTALL.md](INSTALL.md)
4. Restart affected services after configuration changes
